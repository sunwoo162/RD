# RD — RepoDock

> Your code, already here.

RD는 사용자가 **직접 등록한 GitHub 저장소만** 원하는 로컬 폴더로 안전하게 동기화하는 초경량 오픈소스 프로젝트입니다.

## 제품 방향

- 저장소 URL과 저장 위치를 지정해 Clone
- 새 원격 커밋을 주기적으로 확인
- 로컬 변경·브랜치 분기·Git 작업 중에는 자동 업데이트 차단
- 저장소 개수에 인위적인 제한 없음
- Rust 기반 백그라운드 Agent, 필요할 때만 실행하는 UI
- 기본은 수동 승인, 자동 동기화는 저장소별 명시적 선택

> 현재 프로젝트는 개발 초기 단계입니다. 설치형/무설치형 Windows 앱은 아직 배포되지 않았습니다.
