# RD 동기화 안전 정책

- 등록한 GitHub 저장소만 관리합니다.
- 최초 Clone은 존재하지 않는 폴더에서만 수행합니다.
- 자동 동기화는 저장소별 `auto` 설정이 명시된 경우에만 활성화합니다.
- 현재 브랜치를 임의 전환하지 않습니다.
- 원격과 로컬 커밋 이력이 분기된 경우 자동 업데이트를 중단합니다.
- 추적되지 않은 로컬 변경 파일이 있거나 작업 트리가 수정된 경우 자동 업데이트를 중단합니다.
- Git Merge/Rebase 등 진행 중일 때 자동 업데이트를 중단합니다.
- Fast-forward 방식으로만 갱신합니다.
- 강제 Push, 강제 Reset, Git Clean, 자동 Stash, 자동 Rebase는 하지 않습니다.
- 원격에서 추적 파일을 삭제한 경우 정상적인 Fast-forward 동기화에서도 해당 파일이 로컬에서 삭제될 수 있습니다.
- 외부 프로그램의 동시 Git 조작까지 전부 막을 수는 없습니다.
- 성능 예산(유휴 RAM 30MB, CPU 0.1%)은 아직 실측되지 않은 목표값입니다.
